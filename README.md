## 📌 حالة المشروع

| المهمة | الحالة |
| :--- | :---: |
| **النصوص والقائمة الرئيسية** | ✅ تم |
| **الحوارات والنصوص الأساسية** | 🚧 قيد العمل |
| **الرسوميات والخطوط** | ⏳ بانتظار البدء |
| **مراجعة وتدقيق النصوص** | ⏳ بانتظار البدء |

## 🛠️ طريقة التثبيت
> ⏳ **قريباً:** سيتم إرفاق ملفات التعريب والشرح التفصيلي فور جاهزية النسخة التجريبية الأولى.

## ⚠️ ملاحظات مهمة
> التعريب ما زال في مرحلة التطوير، يُفضل دائماً أخذ نسخة احتياطية من ملفات اللعبة الأصلية قبل تثبيت أي ملفات مستقبلاً.
