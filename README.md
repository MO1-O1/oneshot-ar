# 🌟 تعريب لعبة OneShot

مشروع تعريب عربي غير رسمي للعبة **OneShot**. يهدف المشروع إلى إتاحة تجربة اللعبة باللغة العربية مع الحفاظ على طابعها الخاص وأجوائها الفريدة.

---

## 📌 حالة المشروع
- **حالة التعريب:** قيد التطوير 🚧
- **نسبة الإنجاز الإجمالية:** ~30% (تقريبي)

### تفاصيل التقدم:
-  النصوص القائمة الرئيسية (تم)
-  الحوارات والنصوص الأساسية (قيد العمل)
-  الرسوميات والخطوط
-  مراجعة وتدقيق النصوص
